# صفحة نوف خبتي

صفحة تعريفية عربية متجاوبة جاهزة للنشر على GitHub Pages.

## النشر
1. أنشئي مستودعًا باسم `nouf-profile` في حساب GitHub.
2. ارفعي الملفات داخل هذا المجلد مباشرة إلى جذر المستودع، وليس ملف ZIP.
3. من Settings → Pages اختاري Deploy from a branch ثم main و / (root)، واضغطي Save.
4. انتظري ظهور رابط النشر. استخدمي الرابط النهائي لإنشاء رمز QR، وجرّبيه بالجوال قبل الطباعة.

## مراجعة قبل النشر
- رابط LinkedIn الذي زوّدتِنا به: https://www.linkedin.com/in/noof-khabti .
- صيغ الجوائز مستندة إلى المعلومات التي شاركتِها سابقًا؛ راجعي مسمياتها قبل النشر.
- أرقام الهاتف والبريد عامة على الصفحة كما طلبتِ.
- الرسم للسرير توضيحي؛ يمكن استبداله بصورة النموذج الفعلي.

## التعديل
النصوص والألوان والروابط في index.html. حدّثي بيانات ملف nouf-khabti.vcf عند تغيير وسائل التواصل أيضًا.
لا توجد خدمات مدفوعة أو قاعدة بيانات. خط Google اختياري؛ يوجد خط بديل عند عدم الاتصال.

## اللغات
